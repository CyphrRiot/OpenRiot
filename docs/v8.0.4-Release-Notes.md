---

## Release Overview

OpenRiot 8.0.4 walks the package pins to current stable. The OpenBSD
8.0 package tree moved after the 8.0.0 pins were taken, and some
packages had moved by a distance that matters.

The release also catches one dead path in the migration code that
`go vet` flagged. The deletion summary after a backup cleanup was
written as unreachable. It no longer is.

**Total changes: three pins walked forward, one dead path removed.**

---

## The Receipt

Three stable package updates landed since the 8.0.0 pins were captured:

| Package | Old pin | New pin |
|---------|---------|---------|
| Firefox | 157.0p0 | 158.0.1 |
| ImageMagick | 6.9.13.55 | 6.9.13.59 |
| rclone | 1.75.1 | 1.75.2 |

The pins were refreshed from a fully updated 8.0 install with
`openriot --sync-packages`.

The sync writes to the installed copy of `packages.yaml`, not the
repository. The repo copy was manually aligned. The next release will
ship a tree that matches the current stable mirror, so setup does not
immediately need `pkg_add -Iu` after a fresh install.

---

## The Dead Path

`go vet` flagged unreachable code in a migration helper. The function
`deleteExtraFilesFromBackupWithSelectiveSupport` returned the walk
directly without checking its error, so the final deletion summary
never ran. It now captures and checks the walk error before writing
the summary.
