## Release Overview

Notifications move from the top-right corner to dead center.
Width, height, font, padding, and corner radius all scale up
10%. The construct speaks louder and stops covering the buttons
you're trying to click.

The drive manager's softraid guard learns the difference between
an internal RAID chunk and a USB enclosure. External softraid
drives are no longer treated as internal — you can wipe, clone,
and benchmark them without the machine telling you no.

**Total changes: notifications centered and scaled, USB softraid
drives unblocked.**

---

## 📢 Notifications: Centered and Scaled

The old position was `offset = (16, 42)` — top-right corner,
16 pixels from the right edge, 42 pixels from the top. Every
notification landed on top of something you wanted to click.

The new position:

```
origin = center
offset = (0, 0)
```

Dead center. Zero offset. The machine speaks from the middle
of the screen and gets out of the way of your cursor.

Everything else scaled up 10%:

```
        Old         New
Width   450         495
Height  300         330
Font    11pt        12pt
Padding 16          18
Radius  6           7
```

The construct is louder. The text is bigger. The corners are
rounder. The Turing Police would file a bug about "screen
real estate." We filed a bug about notifications covering
buttons and fixed it by moving them to the center.

Run `openriot --dunst-setup` then reload dunst to apply.

---

## 🔌 USB Softraid Drives: Unblocked

The drive manager had a guard: if a drive is a softraid chunk
and not removable, block the action. Wipe, clone, benchmark —
all blocked. The guard was protecting internal RAID members
from accidental destruction.

But USB enclosures with softraid chunks were caught in the
same net. External drives, plugged in via USB, treated as
internal. The machine said "cannot wipe internal softraid
drive" to a drive you could hold in your hand.

The guard now checks the bus type:

```go
if d.IsChunk && !d.IsRemovable && d.BusType != "USB"
```

USB softraid drives pass through. Internal softraid drives
stay blocked. The machine knows the difference between a
drive bolted to the motherboard and a drive sitting on your
desk.

The Feds would call this "device enumeration logic." We call
it not treating your USB enclosure like a server rack.
