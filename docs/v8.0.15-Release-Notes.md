## Release Overview

This is the one where the color migration finishes.

For three releases the desktop has been moving from Bondi Green
to Candy Cyan, one surface at a time. The icon theme changed.
The window borders changed. The selection highlights changed.
The notifications changed. The crypto icon changed. The editor
changed. The only thing left wearing green was the terminal
itself, and now it does not.

v8.0.15 repaints the fish prompt and the Alacritty palette, and
stands back to look at the whole thing at once. What follows is
the complete ledger, so the color story reads as one arc instead
of three patch notes.

---

## Act I: The Candy Man

The folders were the first to move. `candy-kora` shipped as a
bundled icon theme, Candy's gradient apps and folders layered
over Kora's file types. The GTK and XFCE settings pointed at
it, and the accent wheel rolled to `candy-cyan`:

| Key | Color |
|-----|-------|
| `fg` | `#50c9c3` |
| `fg-light` | `#96deda` |
| `dim` | `#37a29c` |
| `bg` | `#1A3330` |

The i3 `client.focused` border followed, so the focused window
matched the folder you were clicking into.

---

## Act II: Paint It Cyan

The hardcoded greens that survived the accent change came next.
`#9ECE6A` was retired from Thunar's selection highlight and the
active tab underline, replaced with `#50c9c3`. The dunst popup
frames moved from lime to `#37a29c`. The crypto icon stopped
being a yellow taxi and joined the teal family with
`${colors.cyan}`. Gnome Text Editor stopped defaulting to
CypherRiot Dark and went back to Tokyo Night Dark.

Every color in that act was a string that remembered the old
accent by heart.

---

## Act III: Cyan Monday

The terminal was the holdout. The fish prompt still painted the
logo, the hostname, and the prompt arrow in green. Alacritty's
palette still called `#9ECE6A` green.

`config/fish/config.fish` now uses `#50c9c3` for the logo, the
prompt arrow, and the upstream-ahead marker, and `#96deda` for
the hostname and git branch. The path stays blue. The error
status stays red.

`config/alacritty/alacritty.toml` changes the `green` entry in
both the normal and bright palettes from `#9ECE6A` to
`#50c9c3`, and the header no longer claims Bondi Green.

A new terminal picks it up. A new shell picks it up. The green
is gone from the last place it lived, which means the migration
is not half done anymore.

---

## The Push Button Retry

The release target used to run `git push && git push origin
v8.0.13`. One transient timeout left main pushed and the tag
stranded, which is the release equivalent of leaving the house
with one shoe.

It now pushes main and the tag together, retrying three times
with a five second pause. A flaky connection costs ten seconds
instead of a broken release.
