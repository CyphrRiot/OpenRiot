## Release Overview

v7.1 fixes every lock screen in the set. The original lock
screen images were placeholders — now replaced with proper,
purpose-designed wallpapers across all 14 lock screens.

The stealth variants (`01s.png` through `04s.png`) are
replaced alongside the standard screens. Your lock screen
finally matches the quality of the rest of the desktop.

The main screenshot (`assets/screenshot.png`) is updated to
reflect the current state of the desktop after all recent
visual changes.
