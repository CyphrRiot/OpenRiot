OpenRiot v3.1 Release Notes

## Release Date: 2026-04-24

--------

## 🚀 New Features

### Go Module System Migration

Complex shell scripts in  packages.yaml  are now proper Go modules with full error handling:

 Module                    │ Command                        │ Notes
───────────────────────────┼────────────────────────────────┼──────────────────────────
  fonts.all                │  openriot --install-fonts      │ Installs Nerd Fonts
  source.bibata-cursor     │  openriot --install-asset      │ Cursor theme
                           │ bibata                         │
  source.kora              │  openriot --install-asset kora │ Icon theme
  source.gurk-keybindings  │  openriot --gurk-setup         │ Configures gurk
                           │                                │ keybindings
  system.mac-spoof         │  openriot --random-mac         │ MAC randomization
  source.rofi-calc         │  openriot --install-rofi-calc  │ Calculator plugin

### New Commands

•  --install-fonts  — Installs Nerd Fonts with skip detection
•  --install-asset <name>  — Installs cursors/icons (bibata, kora)
•  --install-rofi-calc  — Builds rofi-calc from source

### i3 Keybinding Improvements

• Added:  Super + Shift + Arrow  to move windows between split positions
• Added: i3 tutorial video link in README.md
• Both focus and move commands now documented in keybindings table

### New Modules Created

  ├── fonts/fonts.go        # Font installation

•  --install-fonts
•  --install-asset <name>

### packages.yaml Migration

All 6 modules now use Go commands instead of complex shell scripts, providing:

• Better error handling
• Consistent output format ( [SKIP] ,  [DONE] ,  [WARN] )
• Easier testing and debugging
