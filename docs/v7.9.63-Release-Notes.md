## Release Overview

The install instructions stop telling users to delete the GPT boot
partition. The MPD config gets a proper audio buffer so the music
doesn't skip when the machine is busy.

**Total changes: GPT-safe partition instructions, anti-skipping
MPD buffer config.**

---

## 🔧 Install Instructions: Keep the Door Open

The old instructions told users to hit `z` in the disklabel editor.
`z` deletes every partition on the disk — including `i`, the EFI
System Partition that GPT firmware needs to find the bootloader.
Users who followed the instructions exactly had machines that
wouldn't boot.

The new instructions:

```
a (auto) → e (edit) → remove all except i → resize / →
a swap → a /home → w → q
```

Hit `a` first. Auto creates a valid layout with the `i` partition
intact. Then `e` to edit — remove the partitions you don't want,
resize `/` and `/home`, add `swap`. The `i` partition stays. The
door stays open. The machine boots.

A note now explicitly warns: **Do NOT use `z` — it deletes the
`i` partition required for GPT booting.**

Thanks to the user who filed GitHub issue #6 and pointed out that
`z` was breaking their install. The Turing Police would say
"read the manual." We say the manual was wrong and we fixed it.

## 🎵 MPD: The Music Stops Choking

MPD on OpenBSD ships with a 4 MiB audio buffer and no sndio
buffer tuning. When the machine is busy — Firefox eating CPU,
a compile running, the disk grinding — the buffer empties before
the next chunk of audio arrives. The music skips. It sounds like
a scratched CD.

The new `config/mpd/mpd.conf` template ships with:

```
audio_buffer_size  "8192"    # 8 MiB (was 4 MiB default)
buffer_before_play "50%"     # Fill halfway before starting
buffer_time        "2000"    # 2-second sndio hardware buffer
```

Three levers: a bigger MPD internal buffer, a higher fill
threshold before playback begins, and a 2-second sndio buffer
at the hardware level. The machine can get busy for two full
seconds before the audio pipeline notices.

The Turing Police would call it "audio buffer underrun
mitigation." We call it Beck not skipping in the middle of
a guitar solo.
