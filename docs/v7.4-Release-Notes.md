## Release Overview

v7.4 compresses the entire visual layer without touching a pixel.
Every background and lock screen in the repo has been converted from
PNG to WebP at 95% quality. The result is visually identical to the
originals at roughly one-fifth the file size.

| Asset Type | Before | After | Savings |
|------------|--------|-------|---------|
| Backgrounds (22 files) | ~148 MB | ~29 MB | ~80% |
| Lock screens (24 files) | ~144 MB | ~28 MB | ~80% |
| **Total** | **~283 MB** | **~57 MB** | **~226 MB** |

That is not a typo. The wallpaper you stare at all day now loads
faster, clones faster, and takes up a fraction of the disk space.
The lock screen cache builder (`openriot --build-lock-cache`) has
been updated to accept `.webp` source files and rebuild
screen-resolution `.png` caches for i3lock as always. Runtime
behavior is unchanged — only the repo footprint shrank.

We also fixed a long-standing POSIX compatibility bug in the lock
screen cache builder. The `ffmpeg` batch path used `read -d ''`,
a bashism that fails on OpenBSD's `/bin/sh` (pdksh). It now uses a
standard `while IFS= read -r f` loop, so the fast path actually works
on every system instead of silently falling through to ImageMagick.

A new `make convert` target is available for future releases. Run it
to batch-convert any new `.png` assets to `.webp` at 95% quality.
