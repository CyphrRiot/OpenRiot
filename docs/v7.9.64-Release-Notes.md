## Release Overview

The `--crypto ROWML` table is narrower and more honest. The Buy
Limit column is gone — it computed a support level nobody could
trade. The Sell Limit is now Sell Target, because that's what it
always was.

**Total changes: Buy Limit column removed, Sell Limit renamed.**

---

## 🧹 The Buy Limit Column Nobody Traded

Every row printed a "Buy Limit": the 90-day low, nudged 3% up,
then clamped so it never sat more than 20% below spot and never
closer than 5%. The clamp meant it never landed on anything real.
On a coin already off its lows it pointed at a price that had
passed. On a coin mid-drop it pointed at a floor that kept
moving.

You could not place an order there. You did not act on it. It was
decoration wearing a price tag.

It's gone. The table now carries only the numbers you use.

---

## 🎯 Sell Limit Was the Wrong Name

The surviving column is computed one way: take the 90-day high.
If price is already above it, project a measured move — the
range's own height — above the breakout. If that lands below
spot, fall back to a flat 5%.

That is a resistance target. It is not a limit order. No matching
engine watches it, nothing fills when you touch it. Calling it a
limit taught you to expect an execution that was never there.

Now it reads **Sell Target**, and it means what it says.
