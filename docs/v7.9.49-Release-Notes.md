## Release Overview

`openriot --crypto` now has Buy Limit, Sell Limit, and Dest columns.
Sell limits use six months of range data — sell near the top if you're
close, further out if you're climbing. Buy limits do the inverse. Screen
arrows now show daily movement, not the last 30-second fetch. Rotation
targets multiply range position, upside, and trend with an RSI modifier
so the machine doesn't buy the blow-off top. feh got its arrow keys back.

**Total changes: buy/sell columns, range momentum scoring, daily arrows,
feh fix.**

## 📊 Buy Limit, Sell Limit, Dest

```
Coin    Held    Entry    Price   Value   Gains   Port Buy Limit  Sell Limit Dest
BTC    0.5000   60,000   63,000  31,500   +5.0%  33.3% @ $62.0k   @ $72.0k   →ETH
ETH      5.00    3,000    3,200  16,000   +6.7%  33.3% 1 @ $3,000  1 @ $3,500  →BTC
SOL    200.00      100      105  21,000   +5.0%  33.4% 40 @ $95   40 @ $120   →ETH
```

**Buy Limit** — range-based, inverted: near the lows → buy near the low.
Mid-range → buy on pullback. Near highs → buy on deep dip. Prices ≥ $10k
use k-suffix. Drops the units if the column overflows.

**Sell Limit** — range-based: near highs → sell near the top (×0.98).
Mid-range → sell with room (×0.90). Near lows → wait for recovery (×0.75).
Prices ≥ $10k compacted.

**Dest** — rotation target, extracted to its own column. Best performer
rotates to second-best. ZEC → SOL, everyone else → ZEC.

The "Entry" header is now "Gains" — one character shorter.

## 🔄 Range Momentum + RSI

```
score = position × upside × trend × rsiMod
```

The old RSI-only logic made LTC look like a good idea. The new score
uses actual price history: where in the 6-month range, how much room
to run, whether the coin is trending up, and an RSI fine-tune (±5-15%).

## 📈 Daily Arrows, Not Fetch Noise

Price arrows now compare current price against yesterday's OHLC close,
not the previous 30-second fetch. You see the actual daily direction.
