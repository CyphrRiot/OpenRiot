# OpenRiot v6.10 — New Canvas

> _"The wallpaper is the first thing you see and the last thing you notice."_
> — every desktop ricer, eventually

---

## Release Overview

v6.10 replaces the entire OpenRiot desktop background collection.
Twenty-one new images ship as `01.png` through `21.png`, replacing the
previous set. All are 1920x1080 or higher, dark-theme compatible, and
selected to work with OpenRiot's purple-cyan polybar palette.

No code changes. No new features. Just new walls.

---

## 🖼️ New Backgrounds

The old collection had accumulated duplicates, mismatched aspect ratios,
and images that clashed with the dark UI. The new set is cohesive,
curated, and consistently sized.

- **21 images** (was 29 — duplicates and low-quality files removed)
- **Sequential numbering** — `01.png` through `21.png`
- **Dark-theme compatible** — all work with the default i3/polybar scheme

Cycle with `Super + W` (next) and `Super + Shift + W` (previous).
