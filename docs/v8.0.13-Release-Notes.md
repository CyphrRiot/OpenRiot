## Release Overview

v8.0.13 ships a new default icon theme and repaints the accent
to match it.

The installer now bundles `candy-kora`, a hybrid of Candy's
gradient app icons and folders with Kora's file-type icons.
The GTK settings and the XFCE icon setting both point at it.
The accent wheel moves from bondi-green to candy-cyan, so the
focused window border and the workspace highlight agree with
the folders.

No new daemons. No new keybindings. A lot of color.

---

## The Candy Man

Kora's app icons are excellent. Candy's folders are excellent.
Nobody wants to choose between them, and now nobody has to.

`candy-kora` is Candy as the base: gradient folders, app icons,
devices, status glyphs. Kora's `mimetypes` directory is layered
on top, replacing the file-type icons with the fuller Kora set.
The result is Candy folders you can see across the room and
Kora documents you can tell apart at a glance.

The theme is bundled as `assets/themes/candy-kora.tgz`. A new
`--install-asset candy-kora` path extracts it, and the `kora`
installer module installs both themes together. `make validate`
now checks that the archive is present before a release.

Both GTK settings files and the XFCE `IconThemeName` point at
`candy-kora`, so the file manager and the settings daemon stop
arguing about which icon set is in charge.

## The Cyan Shift

The accent wheel leaves green behind. `config/colors.toml` now
reads:

| Key | Color |
|-----|-------|
| `fg` | `#50c9c3` |
| `fg-light` | `#96deda` |
| `dim` | `#37a29c` |
| `bg` | `#1A3330` |

Polybar reads the same palette, so the focused workspace and
window title move together. The i3 `client.focused` border uses
`#37a29c` with a `#50c9c3` indicator. The folders were cyan.
Now the whole room is cyan, the way it always meant to be.

Gnome Text Editor is unchanged. It was already Tokyo Night Dark,
and it is staying that way.
