## Release Overview

The Control Center stops freezing when you press a key, and
`--convert-webp` stops deleting images it was never asked to
touch. One is a UI that couldn't move; the other was data loss.

**Total changes: actions moved off the UI thread, a display
refresh, key-collision cleanup, cursor clamping, and a
destructive converter bug fix.**

---

## ⏳ The Panel Learns to Wait

Every action in the Control Center ran on the drawing thread.
Press WireGuard and the panel froze while `doas wg-quick up`
stood the tunnel up and then polled it for up to ten seconds.
Press the update row and it froze on a version check with a
ten-second HTTP timeout. Press screenshot and it froze until
`maim` returned. The user saw a dead window and assumed the
panel had crashed.

The fix is the shape it should always have had: every action
now runs off the UI thread and the panel refreshes itself the
moment the action finishes. Press WireGuard and the label
flips to `[ON]` a second or two later — truthful, not guessed.
Nothing blocks the drawing thread. The construct keeps
breathing while the tunnel comes up.

While the panel was open to change, it also started refreshing
brightness and HDMI on the same timer as everything else, so
the brightness keys and external-display changes land in the
panel instead of going stale.

---

## 🖼️ The Converter Was Eating the Pictures

`openriot --convert-webp` was built to turn `backgrounds/` and
`Locked/` PNGs into WebP and delete the source PNGs. Somewhere
along the way it learned a second trick: it globbed every
`*.webp` in its target directories and **deleted any that had
no matching `.png`** as "stale."

Two things were wrong with that. First, the normal end state of
a converted file *is* a `.webp` with no `.png` — the tool
deletes the PNG itself. So the converter would have eaten its
own output on the second run. Second, `assets/` had been quietly
added to the target list, and every image there — the ones the
README shows you — is a standalone `.webp` with no PNG. One run
deleted nineteen of them.

The converter now does one thing: it converts the PNGs in
`backgrounds/` and `Locked/`, removes the source PNG, and never
touches anything else. `assets/` is out of its reach.

## 🎯 Small Truths

- **Proton Drive hides** in Privacy when it isn't configured,
  matching the bar module that already auto-hides.
- **The faders icon** moved to sit beside the gear on the bar
  and now wears the same color as its neighbors.
- **The cursor clamps** when a row disappears, so it can't sit
  on a button that isn't there.
- **One action key.** The `p`/`r`/`s`/`l` shortcuts are gone.
  `enter` is the only action, so `l` no longer means both "next
  section" and "lock."
- **The binary is called by path,** not by hoping `PATH` is set
  in a GUI session.
- **Tests exist.** The Control Center has its first unit tests.
